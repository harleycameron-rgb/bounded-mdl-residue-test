# Vendor Integration Guide
Bounded Predictive‑MDL Residue Test — v1.0.0

This guide explains how external vendors, labs, and model developers can
integrate with the Bounded Predictive‑MDL Residue Test benchmark. It covers
requirements, expected behaviours, and the full evaluation workflow.

## 1. Overview
The benchmark evaluates models under strict MDL‑bounded predictive constraints.
Vendors must implement a deterministic pipeline that produces:
- compressed core
- residue signature
- alignment report
- bounded response

## 2. Required Files
Vendors must provide:
- a Python or JavaScript implementation
- a compliance report generated by the validation suite
- version declaration (must target v1.0.0)
- documentation describing MDL bound handling

## 3. Determinism Requirements
All vendor implementations must be fully deterministic:
- identical inputs → identical outputs
- no randomness
- no adaptive tuning
- no external calls
- no hidden state

## 4. Integration Steps
### Step 1 — Implement the Pipeline
Implement functions equivalent to:
- compress()
- extract_residue()
- check_alignment()
- generate_bounded_response()
- run_full_pipeline()
